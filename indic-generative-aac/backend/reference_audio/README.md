# Native Gujarati reference

`gu_fleurs.wav` is a human Gujarati recording from the FLEURS dataset, not Google TTS or other synthesized audio. It is used only to condition the locally loaded IndicF5 model.

- Dataset: [google/fleurs](https://huggingface.co/datasets/google/fleurs), `gu_in`, validation/dev.
- Original filename: `10175145172467691870.wav` (FLORES sentence 1560).
- Attribution: FLEURS, Google and the FLEURS contributors (Conneau et al., 2023).
- License: [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).
- Recording: distributed unchanged; preprocessing/resampling happens in memory during inference.
- Exact dataset transcript, source URLs and recording SHA-256: `gu_fleurs.json`.
