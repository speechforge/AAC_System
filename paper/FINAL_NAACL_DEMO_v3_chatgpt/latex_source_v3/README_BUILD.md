# Indic AAC Studio: Version 3 review revision

Open `main.tex`. On Overleaf select **XeLaTeX**. The official ACL style files, bibliography, and Noto fonts are supplied. The author list is visible, following the single-blind demo call.

Locally, run `./build.sh` with Tectonic or XeLaTeX installed. To specify Tectonic explicitly, set `AAC_TECTONIC=/absolute/path/to/tectonic` when invoking the build script. The recorded build uses Tectonic 0.17.0.

The PDF has six main-content pages, one page of ethics/acknowledgments/references, and two appendix pages. Source strings are Unicode; native fonts remain upright and the XeTeX path supplies explicit UTF-16 PDF ActualText for faithful extraction.

Editable figures are LaTeX/TikZ sources in `figures/`. The two PNGs are original recorded interface captures. Tables and recorded examples are regenerated by `python3 figure_sources/build_evidence.py` from bundled evidence when this portable package is extracted. No holdout success scores are bundled or reported.

Read `V3_REVIEW_REVISION_NOTES.md` for the claim-evidence boundary, checks, and remaining scientific, citation and release dependencies. The package is for author review and does not establish submission readiness or confer a new license.
